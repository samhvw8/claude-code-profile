# Update Log

## 2026-10-21
* **Update**: Released v0.49.0: [release history](/product/release-history.md), version in `CLAUDE.md` and `.claude-plugin/plugin.json`.
* **Update**: Split the lock out of `ccp.toml`: each source's `commit`/`checksum` now lives in `~/.ccp/ccp.lock`, and the per-machine `updated` timestamp is gone, so two machines with the same sources write the same bytes. A legacy `ccp.toml` `commit` is read and moved on the next save. `source list` shows COMMIT instead of UPDATED; `bootstrap --push` also adds `ccp.lock`. Updated [ccp.toml](/reference/ccp-config.md), [shadow source items](/decisions/shadow-source-items.md), [source system](/features/source-system.md), [bootstrap](/features/bootstrap.md) and the [command reference](/cli/command-reference.md).

## 2026-10-02
* **Creation**: [Source items are shadows, not copies](/decisions/shadow-source-items.md) — `ccp install` links `hub/<type>/<name>` into the source clone instead of copying it; `--clone` makes an editable local copy (converting a shadow); `ccp.toml`'s `commit` is a lock that sync checks out; `source update` refuses a clone with local edits; `doctor --fix` migrates unchanged copies. Updated [source system](/features/source-system.md), [ccp.toml](/reference/ccp-config.md) and the [command reference](/cli/command-reference.md).
* **Update**: Review fixes (correctness, adversary, maintainer) on [shadow source items](/decisions/shadow-source-items.md): `commit`, `ref` and `url` from `ccp.toml` can no longer pass for git options; a failed lock checkout warns instead of rewriting the lock; sync keeps items it cannot install and finds plugin and URL items by hub name; items resolving outside `sources/` are refused; the local-edit guard ignores stray untracked files; `--clone` also keeps tracked copies and the user's own links as local items; the copy comparison counts modes and empty directories; doctor reports foreign links and sweeps interrupted-migration leftovers; `hub outdated` skips shadows. Relative-link helpers are shared in `internal/symlink`.
* **Update**: Removed GitNexus: the generated block in `CLAUDE.md` and its mention in [knowledge maintenance](/engineering/knowledge-maintenance.md). Code navigation uses the codegraph MCP.
* **Update**: Go 1.25.1 → 1.27.1 in `mise.toml`, `go.mod` and both CI workflows, then `go fix ./...`: `interface{}` → `any`, loops → `slices.Contains`/`maps.Copy`/`min`/`max`/`slices.Backward`/`strings.SplitSeq`/`strings.Cut`/`range n`. No behavior change; tests pass on 1.27.1.
* **Update**: Council review (operator, cost tracer, completionist) on [output styles](/features/output-styles.md): ledger updates are locked and saved even when a carrier fails; a corrupt ledger is moved to `.bak` and rebuilt with a one-line warning; hub rename/remove/update, install and source install/update now follow the active profile; omp's opt-in counts a style carrier ccp owns there ([global context](/features/omp/global-context.md)); sync lines show each carrier's size; deleted carriers are pruned and ones on a missing drive kept; manual syncs of an inactive profile say the next change replaces them; `ccp link --help` explains carrying.
* **Update**: Second review round (correctness, adversary, maintainer) on [output styles](/features/output-styles.md). Carriers are owned through a ledger of path and hash (`~/.ccp/state/output-style-carriers.json`), not the marker: hand edits and planted files are left alone, carriers written under another `PI_CODING_AGENT_DIR`/`XDG_CONFIG_HOME` are kept current or removed, and `ccp reset` re-checks each hash. omp's `APPEND_SYSTEM.md` goes where omp reads it, ignoring `PI_CODING_AGENT_DIR`. One `followHarnesses` hook gives omp's style, pi and opencode the same triggers. Two styles answering to one name carry nothing. `ccp init` moves `~/.claude/output-styles` whole again, keeping hidden files and symlinks. The doc now says `/output-style` choices are project-local and not followed. `ompRulesMarker`/`ompWriteFileAtomic` became `generatedMarker`/`writeFileAtomic`.
* **Update**: Review fixes for [output styles](/features/output-styles.md): an unreadable style file or `settings.json` no longer removes carriers or fails omp/opencode syncs; `ccp reset` removes pi's and opencode's style files; pi's `APPEND_SYSTEM.md` no longer counts as an omp opt-in ([global context](/features/omp/global-context.md)); the opencode `instructions` hint appears only for a file ccp owns ([opencode](/features/opencode.md)); the symlinked-type-directory guard now runs before any change and also covers bundle linking and drift detection; in `output-styles/`, ccp removes only unlisted hub links.
* **Creation**: [Output styles](/features/output-styles.md) — `output-styles` is a hub item type linked into Claude Code like commands. The style that `outputStyle` selects is carried into omp (`APPEND_SYSTEM.md`, in [global context](/features/omp/global-context.md)), into pi (new hidden `ccp pi sync`), and into [opencode](/features/opencode.md) (`output-style.md` plus an `instructions` hint). ccp now refuses to link into a profile type directory that is a symlink. Updated the [command reference](/cli/command-reference.md), [project setup](/features/project-setup.md), [profile manifest](/reference/profile-manifest.md), [core concepts](/product/core-concepts.md), [key types](/architecture/key-types.md) and [directory layout](/architecture/directory-layout.md).
