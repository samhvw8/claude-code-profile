# Reference

* [profile.toml manifest](profile-manifest.md) - Schema of the per-profile manifest that declares which hub items and settings template a profile uses.
* [ccp.toml configuration](ccp-config.md) - Global ccp configuration — default registry, registry settings, and the auto-managed list of installed sources.
* [.ccp.yaml project config](project-config.md) - Project-level file that names a profile for automatic selection with ccp auto.
* [Hub hooks format](hooks-format.md) - How hub hooks are stored (Claude Code hooks.json plus scripts), the Go types, event names, and how they reach settings.json.
* [Settings templates and fragment capture](settings-templates.md) - Complete settings.json files stored in the hub and referenced by name, plus capturing manual edits as a per-profile fragment.
